# M2 工作日志

本文件只由 M2 追加，其他成员不要编辑。新条目追加在文件末尾。

条目格式（照抄下面这一段，逐行填写，目标是 1 分钟内写完）：

```
## T-0xx · M2 · YYYY-MM-DD
- 内容:
- 产出:
- 提交:
- 用时:
- AI:  · 校验:
- 状态:
- 备注:
```

字段说明：

- `内容` 实际做了什么。
- `产出` 实际改动/新增的路径，多个用 ` · ` 分隔。
- `提交` commit 短哈希；如果走了 PR，追加 ` · PR #n`。
- `用时` 近似有效工时，按 0.5 h 取整，自报即可。
  工时、提交数、代码行数、提示词条数、token 用量都**不是**贡献度分数，
  不会被单独拿来衡量任何人。贡献度由任务范围、产出、校验方式、提交、
  评审与集成工作、以及日志共同还原。
- `AI` 用了哪个工具；没用就写"无"。`校验` 是**必填**：说明你如何确认
  产出是对的。任务的人类负责人始终是作者，并对结果负责。
- `状态` todo / wip / review / done / blocked / dropped。
- `备注` 阻塞、遗留问题、移交说明。
