# Q4 scale versus non-scale decomposition

Generated by `scripts/q4_evolution_run.py`. Do not edit by hand.

Language: direct panel summaries are observed / descriptive. The residual time component is a
**non-scale-associated historical trend** (a conditional time association): it holds everything that
moved with calendar time at fixed parameter count, including training-data and compute growth that
parameter count does not measure. It is not called algorithmic or technical progress, and nothing
here establishes a causal effect of calendar time.

Uncertainty: 90% month-block bootstrap interval (399 replicates); whole calendar months are resampled.

## A. Broad panel, parameter scale

### Mean capability (exact split, all models)

OLS: `macro = a + b log10 N + g t`, and `log10 N = c + s t`. By the omitted-variable identity the
time-only slope equals `g + b s` exactly (checked to 1e-8), so the change in mean score per year
splits into a scale-associated part `b s` and a non-scale-associated part `g`.

### Frontier

The frontier is the conditional 90th percentile of the macro score (linear quantile regression on time).
Classification for manuscript use (T-011 v3):

- direct frontier time trend = the primary descriptive forecast trend;
- frontier-set scale / non-scale split = a post-failure, model-conditional decomposition;
- additive quantile split = a rejected diagnostic, retained as a negative result.

**Predeclared additive quantile decomposition (rejected diagnostic) - consistency check.** `Q_0.9(macro | log10 N, t) = a + b log10 N + g t`
with the frontier scale path `Q_0.9(log10 N | t) = c + s t`. Quantiles obey no exact identity, so its
decomposed total `b s + g` is checked against the direct frontier trend.

The additive quantile decomposition fails its own check: its decomposed total does not reproduce
the direct frontier trend. The matched-scale diagnostic below shows why - the frontier's time trend
differs strongly by scale band, which one additive slope cannot represent. It is therefore **not**
used to split the frontier trend.

**Frontier-set split (post-failure model-conditional decomposition).** Adopted only after the additive

applied to it when it holds at least 30 models over at least 3 months. It splits the
continuation trend only for the parameter-scale-growth scenarios; the historical / direct-score

### Log compute

OLS `macro = a + k log10 C + g t` (C = C4 training compute in FLOP) with `log10 C = c + s t`; the
time-only slope splits exactly into a compute-associated part `k s` and a non-compute-associated part
`g`. Training compute moves with both parameters and tokens, so this is the decomposition in which
data growth counts as scale.

### Classic IF3

- primary IF3 decomposition (inside-box rows only): **not supported** - n = 6; fewer than 10 inside-box rows; all of them score between 5.07 and 7.17, at the benchmark floor
- extrapolation sensitivity (all D-inferred rows, 49 of 55 outside the box - **extrapolation**): `macro = a + k L_IF3 + g t` gives k = -32.61 pts per unit loss, g = 4.77 pts/yr

Classic-IF3 caveat, carried from T-008: the principal B1 fit supports estimator / generator recovery,
not precise real-world scaling; external support is B4 with the overlapping Pythia rows excluded and
B5. The IF3 loss above is a model-conditional scale index, and outside the box an extrapolation.
