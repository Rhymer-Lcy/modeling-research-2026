## Decision

**Generalized quality-aware IF3: NOT ADOPTED.** The classic N-D IF3 is the
final, canonical T-008 scaling interface for downstream use.

Reasons, each computed below:

1. **No first-party mapping binds the candidate's quality axis to IF1's.** The candidate's Q is B7's `Q_score`; the only real quality any downstream task can supply is IF1's Q, a relative midrank score whose pooled reference is 0.5 by construction. The binding guard refuses the pairing (no first-party mapping from IF1_Q to B7_Q_score; a monotone relation, a similar range or a convenient normalisation does not establish scale equivalence). This is a v4 STOP condition for the generalized route; it does not affect the classic IF3.
2. **Adoption gate(s) failed: GQ4, GQ5, GQ7.** Details below.

Adoption rule, fixed in the script before any fit ran: adopt only if GQ1-GQ5
and GQ7 all pass **and** a first-party mapping binds the quality axis. GQ6 is a
requirement on an emitted object, not evidence, and is reported for completeness.
